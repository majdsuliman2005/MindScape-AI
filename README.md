# MindScape

A simple web application to manage daily tasks and improve productivity.

## Description
This project helps users organize their daily tasks easily by adding, editing, and tracking tasks.

## Tech Stack
- ASP.NET Core MVC
- SQL Server
- Entity Framework Core
